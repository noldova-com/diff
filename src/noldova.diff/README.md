# @noldova/diff

Line and character diffs, and a 3-way merge of line sequences, with no framework and no DOM, shaped as a CONTEXT package so it can move there.
`TextDiff.lines` and `TextDiff.characters` give an edit that turns the original into the modified text, as `DiffChange` spans, the shortest unless a long text's anchors or words-first pass, or a cost cap, cut it short; `Merge3.lines` splits base, ours and theirs into unchanged, one-sided, same and conflicting regions.
[The repository's README](https://github.com/noldova-com/diff#readme) says how to install and use it.
